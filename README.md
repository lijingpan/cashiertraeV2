# 离线电子秤收银

从 [cashiertraeV2](https://github.com/lijingpan/cashiertraeV2) 下载并独立放在 `electronic-scale/`。这是 Android 横屏 Flutter 应用，商品保存在设备本地 SQLite，串口读取电子秤，USB 热敏打印机打印小票；日常称重和收银不需要网络。

## 使用

1. 首次安装默认显示英文；可在收银页面右上角切换 English、ไทย、中文，选择会保存在设备上。
2. 首页上半部常驻大数字键盘，默认选中通用称重商品“称重商品 / Weighing Item”；即使原菜单为空，也可直接输入单价并称重。左侧选中其他商品后同样可用大键盘临时改价，加入购物车后本单按输入价格计算，菜单原价不变。重量或单价变化时立即显示本件金额，购物车在下半部。点击“保存默认价格”或在设置页修改默认称重单价后会在重启时保留。示例默认价为 ฿1/kg，正式开单前请改为实际价格。已有菜单不会被覆盖；其他商品可在“菜单管理”添加，英文名必填，泰文和中文名选填。界面、顾客副屏和小票按当前语言选择商品名；缺少译名时回退到已有名称。
3. 在“设置”填写秤的串口路径和波特率。原仓库默认 `/dev/ttyS4`、`9600`，请按实际设备修改；点击“测试串口连接”检查当前输入值，再保存。
4. 按公斤计价时，将商品放上秤，等待重量稳定后加入购物车。串口数据无效或超过 3 秒没有更新时，旧重量不能入单。按件计价不需要连接秤。连接到兼容的秤并收到有效报文后，首页显示“去皮”和“置零”；秤未连接或协议无效时隐藏。操作仅在读数稳定时可用，提示“指令已发送”表示串口写入成功，是否生效以秤回报的状态和重量为准。
5. “设置 → 打印小票”默认开启。开启时需要可用的打印机（SUNMI T2 使用内置打印机，其他设备使用支持的 USB 打印机），收到打印成功回执才会清空本单；失败时保留购物车。关闭后按钮变为“完成本单”，无需打印机即可结单。该开关保存在本机，重启后仍生效。未设置店名时，小票票头也使用当前语言的默认店名。
6. 可选的离线商品识别：在“菜单管理”中新建具体商品，点击该行摄像头图标拍摄几张不同角度的样本；首页摄像头拍摄后会列出最多 3 个相似商品。相似度是图像特征比较值，并非识别正确率。收银员确认商品后才带入单价，不会自动加入购物车或出票。样本保存在本机 SQLite，可用商品行的清除按钮删除；删除商品时样本也会删除。没有样本时仍可使用通用称重商品和手动选择。拍摄图像只用于本机推理，临时图像处理后删除。

称重按克、价格按分计算，每行金额四舍五入到分。例如 `0.695 kg × ฿1/kg = ฿0.70`，主屏、副屏和打印单使用相同金额。

## 设备范围

- 秤：原仓库 `serialport-1.1.0.aar` 支持的 Android 串口设备和现有 16 字节报文协议；计价单位为 kg。其他协议或端口需要适配。
- 打印机：SUNMI T2 优先使用内置打印服务；非商米设备沿用原仓库 `autoreplyprint.aar` 支持的 USB 58 mm 热敏打印机，自动查找 VID `0x4B43` 或 `0x0FE6`。其他打印机需要扩充识别和打印驱动。
- 若设备限制串口读写权限，需按设备厂商说明授权；单纯安装应用不能解除系统权限限制。
- AI 摄像头：使用 Android Camera2/CameraX 和随 APK 提供的 [Google MediaPipe MobileNetV3 Small 图像嵌入模型](https://ai.google.dev/edge/mediapipe/solutions/vision/image_embedder/android)；样本匹配完全在设备端进行，不需要付费 SDK、供应商密钥或联网。需要设备摄像头能产生正常亮度的图像；过暗图像会被拒绝。用户提供的创迹 SDK 未打包。

## 开发构建

需要 Flutter SDK（Dart SDK 与 `pubspec.yaml` 的 `^3.10.7` 兼容）、Android SDK 和 JDK 17。
副屏插件 `presentation_displays` 的 Android 兼容修正版已放在 `vendor/presentation_displays/`，构建时使用项目内版本，无需修改全局 Pub 缓存。

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

APK 输出在 `build/app/outputs/flutter-apk/app-release.apk`。当前 Android release 构建配置仍使用调试签名，仅适合内部设备试用。正式分发前需要配置专用签名并在目标秤与打印机上实测。

已在 Android 35 模拟器断网验证应用启动、打印开关重启保留、创建按件商品、加入购物车及无打印结单。

已在 SUNMI T2（Android 7.1.1）真机安装 `1.0.2+3`，创建按件商品、加入购物车并完成一笔 ฿1.00 的打印订单。商米打印服务返回事务打印成功（`onPrintResult code=0`），应用随后清空购物车；测试商品已删除。未接入实体电子秤，真实串口称重仍需在接好秤后验证；也未用外部摄像头核对纸张内容。原有 `com.vdamo.poshost` 应用未改动。

已在另一台 Rockchip `rk3568_r`（Android 11，带电子秤和 USB 打印机）通过无线调试安装 `1.0.4+5`。设备的 `/dev/ttyS4` 可用，USB 打印机为 `VID 0x4B43 / PID 0x3538`。放置实物后读到稳定的 `0.695 kg`，按公斤商品的主屏和顾客副屏均显示 ฿0.70；打印日志中的重量、单价和总价一致，USB 位图打印及切纸均返回成功，随后购物车清空。按件商品 ฿1.00 也已完成一次下单打印测试。测试商品已删除，设备原有 `com.vdamo.cashier` 未覆盖。未用外部摄像头核对实际纸张内容。

`1.1.0+6` 将首次安装、Android 桌面名称、顾客副屏和小票默认文案改为英文。切换泰文或中文后，小票使用对应语言的店名默认值、商品译名和合计标签；旧菜单数据通过数据库升级保留。已在 Rockchip 真机升级安装，核验英、泰、中三种语言下主屏和顾客副屏同步切换，重启后英文选择保留。英文测试单的 USB 位图打印和切纸均返回成功；测试商品已删除。未用外部摄像头核对纸张内容。当前货币仍为泰铢（฿）。

`1.1.1+7` 在新建数据库及空菜单升级时预置多语言称重商品；首页也始终提供通用称重入口，即使商品表为空仍可使用。首页常驻大数字键盘、实时显示本件金额，下半部显示购物车；默认商品和左侧选择的其他商品都可直接改本单价格。已在 Rockchip `rk3568_r` 真机覆盖安装与 GitHub 附件相同的通用 APK：秤和 USB 打印机均连接，稳定读数 `0.265 kg`，临时输入 `฿1/kg` 后本件和购物车金额均为 `฿0.27`；下单打印日志显示中文商品名、重量、单价和合计一致，打印图像与切纸均返回成功，购物车随后清空。关闭打印开关后再以相同重量完成一笔不打印订单，购物车清空且没有新增打印调用；测试后已重新打开打印，并保留设备原有默认价格。此前也验证过 `0.100 kg` 与 `0.245 kg` 的称重商品入单，置零指令串口发送成功。尚未用外部摄像头核对实体小票纸张。APK 在 GitHub Releases 提供下载。

离线 AI 摄像头开发版已在同一 Rockchip 设备安装：Camera2 能识别 USB 摄像头并完成拍照，本地图像嵌入推理、样本保存和候选确认流程均能运行；但实拍帧平均亮度仅 `0.9/255`，几乎全黑。两张黑图会得到虚假的高相似度，因此开发版增加了过暗图像拒绝和提示。需要确认镜头位置、遮挡、补光或设备摄像头供电后，再用真实商品样本验证识别；此开发版尚未替换 GitHub Release 安装包。
